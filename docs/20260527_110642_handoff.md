# Handoff: staged MNIST NeuPSL data layout

Timestamp: 2026-05-27 11:06:42 Asia/Shanghai

## Current Goal

The project has been reorganized so MNIST data preparation is staged by use case:

- supervised Transformer pretraining,
- NeuPSL fine-tuning/training,
- held-out inference.

The notebooks should read prepared data instead of creating their own ad hoc splits.

## Canonical Data Layout

Current generated data lives under:

```text
data/experiment_mnist-1/
├── pretrain/
│   └── size_20000-valid_5000-overlap_0.40/
├── neupsl-train/
│   └── size_1000-valid_1000-overlap_0.00/
└── inference/
    └── size_5000/
```

Current result path:

```text
results/train_1000_infer_5000/
```

The old `data/generated`, `split::xx`, `train-size::xx`, `overlap::xx`, and `test` file naming paths have been removed from active code and README usage.

## Default DatasetConfig

`utils.config.DatasetConfig` now defaults to:

```python
DatasetConfig(
    name="mnist-1",
    pretrain_size=20000,
    pretrain_valid_size=5000,
    pretrain_overlap=0.4,
    train_size=1000,
    valid_size=1000,
    inference_size=5000,
    overlap=0.0,
)
```

Path helpers:

- `pretrain_dir(config)` -> `data/experiment_mnist-1/pretrain/size_20000-valid_5000-overlap_0.40`
- `neupsl_train_dir(config)` -> `data/experiment_mnist-1/neupsl-train/size_1000-valid_1000-overlap_0.00`
- `inference_dir(config)` -> `data/experiment_mnist-1/inference/size_5000`
- `result_dir(config)` -> `results/train_1000_infer_5000`

## Main Files Changed

- `utils/config.py`: staged config fields and canonical path helpers.
- `data/generator.py`: added `generate_experiment_datasets()` and `write_partition_data()`.
- `scripts/create_data.py`: generates pretraining and NeuPSL/inference data in one pass.
- `scripts/pretrain_transformer.py`: reads only `pretrain_dir(config)`.
- `scripts/neupsl_train.py`: reads `neupsl_train_dir(config)` and `inference_dir(config)`.
- `psl/runner.py`: uses `image-*-inference.txt` for PSL inference.
- `notebooks/02_training_demo.ipynb`: reads prepared NeuPSL data; no longer generates data.
- `notebooks/03_inference_demo.ipynb`: reads prepared inference data from `inference_dir(config)`.
- `README.md`: updated project usage and CLI flow.
- `scripts/evaluate.py`: combines runtime output and text-log parsing.
- `models/transformer.py`: supervised fit helper was removed; pretraining uses the explicit loop in `scripts/pretrain_transformer.py`.

## Important Design Notes

Pretraining uses only `train` and `valid` partitions.

NeuPSL data contains `train`, `valid`, and `inference` partitions. The PSL runtime still has an internal `infer` phase, but that phase now points to the held-out `inference` files rather than old `test` files.

`valid_size=1000` is preserved for NeuPSL data so validation artifacts are available for checks and future notebook work, even though the current PSL runner mainly consumes train and inference partitions.
